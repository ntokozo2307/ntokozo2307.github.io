## 📋 About

This is my professional portfolio built with modern web standards:

- **Zero `<div>` tags** — pure semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<figure>`, `<footer>`, `<time>`, `<pre>`, `<fieldset>`, `<output>`)
- **Fully responsive** — mobile-first design with breakpoints for tablet, mobile, and small screens
- **Dark cybersecurity theme** — indigo/cyan gradient accents
- **Interactive animations** — canvas particle system, animated skill bars, terminal typing effect
- **Separated concerns** — HTML, CSS, and JavaScript in individual files

## 🚀 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/ntokozo2307/ntokozo2307.github.io.git
   cd ntokozo2307.github.io
   ```

2. Open `index.html` in your browser, or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000

   # Using Node.js (npx)
   npx serve .
   ```

3. Visit `http://localhost:8000`
